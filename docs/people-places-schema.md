## 決定した項目（2026-11-27 ユーザー承認、decisions #29～#34）

### 人物

| 判定 | 項目（キー） | 備考 |
|---|---|---|
| 残す | 名前（ファイル名・`name`）、読み `reading`、呼び名 `aliases` | 名前の変更はアプリではしない（リンクが切れるため） |
| 残す | 誕生日 `birthDate` | カレンダーの誕生日表示に使われている |
| 残す | 好きなもの `likes`・苦手なもの `dislikes` | |
| 残す | 出会ったきっかけ `metHow`・学校 `school`・会社 `company`・役割 `position` | 既存ノートの名前と一致すると `"[[名前]]"` のリンクで保存 |
| 残す | 家族（本文 `## 👨‍👩‍👧‍👦 人間関係・家族` の `- 配偶者::` など） | 人物から選ぶ（リンク）か文字で追加 |

| 追加 | 間柄 `relation`（家族／友達／学校／仕事／その他） | 既存の人物は下書きを自動で入れる |
| やめる | metDate、bloodType、allergies、futureGoals、strengthsSelf、strengthOthers、location、保有資格、現在部署、従業員番号、所属履歴 | 画面に出さない。既存ノートの値は残す。新しいノート・テンプレートには入れない |

### 間柄の下書きのルール（`src/vault/relation.ts`）

1. 家族欄にリンクがある人、または誰かの家族欄からリンクされている人 → 家族
2. `school` にリンクがある、または所属履歴に学校ノート（`15_Schools`）がある → 学校
3. `company` が入っている → 仕事
4. 出会ったきっかけが学校ノート → 学校
5. それ以外 → その他

2026-11-27 の実データでは 家族34・学校12・仕事3・その他3 人。本人の家族とつながっていない家族（友人一家など）も「家族」になるので、一覧で確認して直す。

### 新しい Dataview（`src/vault/queries.ts`）

- 人物: `FROM "30_HumanNetwork/30_Events" OR "40_Diary"`、`WHERE contains(default(human, []), this.file.link) OR contains(file.outlinks, this.file.link)`
- 場所: 同じく `place` と `file.outlinks`
